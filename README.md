# HighCode Class Operations

מערכת web לניהול פעילות כיתתית: משתמשות, מטלות, לוח מודעות, תורנות חלב, לוח שנה ושליחת התראות במייל.

## מבנה הפרויקט

```text
class-app-backend/
├── app.js                 # יצירת והגדרת אפליקציית Express
├── server.js              # נקודת ההפעלה של השרת
├── package.json           # תלויות ופקודות הרצה
├── data/                  # חיבור למסד הנתונים ושכבת הנתונים
├── routes/                # כתובות ה-API לפי תחומי המערכת
├── controllers/           # נקודות הכניסה של בקשות HTTP
├── services/              # לוגיקה עסקית ושירותים חיצוניים
├── middleware/            # פונקציות משותפות לפני עיבוד בקשה
├── database/              # אתחול ועדכון סכמת מסד הנתונים
├── frontend/              # קבצי הממשק בדפדפן
└── docs/                  # תיעוד ארכיטקטורה ותהליך העבודה
```

## הפעלה

1. מתקינים Node.js ו-PostgreSQL.
2. מעתיקים את `.env.example` ל-`.env` ומעדכנים את הערכים.
3. מתקינים תלויות:

```bash
npm install
```

4. מאתחלים את הטבלאות:

```bash
npm run db:setup
```

5. מפעילים את השרת:

```bash
npm start
```

המערכת זמינה בכתובת `http://localhost:3000`.

## בדיקת תקינות

```text
GET http://localhost:3000/api/health
```

הנתיב מחזיר תשובת JSON קצרה ומאפשר לוודא שהשרת עלה.

## שמירה על קישורים

כתובות ה-API, שמות הקבצים של ה-frontend והפקודות הקיימות נשמרים. שינויי המבנה משתמשים בנתיבים יחסיים מעודכנים ובקבצי תאימות במקומות שבהם היה נתיב ישן, לכן אין צורך לשנות את הקישורים בדפדפן או ב-Postman.

## אבטחת קבצים

אין להגיש את `.env` או את `google-key.json`. הם מוחרגים מ-Git. מגישים רק את `.env.example` עם שמות המשתנים וללא סודות אמיתיים.
